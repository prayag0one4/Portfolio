# Prayag Raj — Portfolio

Personal portfolio website built with **React + Vite**, featuring a Terminal Protocol design with dark/light theme, scroll-snap sections, and framer-motion animations.

## Tech Stack

- **React 19** + **Vite**
- **Framer Motion** — scroll-in animations
- **Pure CSS** — custom properties for theming, glass morphism cards

## Sections

- Hero — typewriter animation, code editor card with syntax highlighting
- About — profile photo with hover color reveal
- Skills — grouped tech stack cards
- Projects — VersionVista, PayU, MagnetDrop with live links
- Experience — Hans International with visit site link
- Leadership — TGCC Finance Lead & PR Outreach roles
- Contact — form with real contact info
- Footer

## Getting Started

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
```
